# Java Shopping Calculator

A simple, interactive Java console application that calculates the total cost of purchasing a specific quantity of an item, complete with euro currency formatting.

---

## Features

- **Interactive User Input:** Prompts the user to input the item name, unit price, and quantity using `java.util.Scanner`.
- **Dynamic Calculation:** Computes the total cost by multiplying the unit price by the quantity.
- **Unicode Currency Support:** Uses Unicode character representation (`8364` -> `€`) to display the currency symbol properly[cite: 1].
- **Clean Console Output:** Outputs a summary of the transaction including item quantity, item name, and formatted total cost[cite: 1].

---
