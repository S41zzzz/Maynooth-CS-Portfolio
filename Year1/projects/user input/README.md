# Java Mad Libs Game

A simple interactive **Mad Libs** console game written in Java. This project demonstrates basic input/output operations, string concatenation, and the use of the `Scanner` class to handle user input.

---

## Features

* **Interactive Prompts:** Asks the user for specific parts of speech (adjectives, nouns, verbs).
* **Dynamic Storytelling:** Generates a customized story using the words provided by the user.
* **Resource Management:** Properly closes the `Scanner` object to prevent memory leaks.

---

## How to Run

1. Make sure you have the Java Development Kit (JDK) installed on your system.
2. Save the code into a file named `Main.java`.
3. Open your terminal or command prompt and compile the program:
   ```bash
   javac Main.java
