# Maynooth CS Portfolio

Welcome to my computer science preparation repository! This collection contains my coding projects, exercises, and practice as I prepare for my studies at Maynooth University.

## Projects

* Java Mad Libs Game - A basic console input/output game practicing the `Scanner` class and string concatenation.
* Shopping Cart Repo - A console-based shopping cart application implementing object-oriented principles, item management, and total price calculation.
* Compound Interest Calculator - A financial calculation tool using user input loops and math formulas to compute compound interest over time.
* Weight Converter - A practical utility program for converting weights between different units using conditional logic and methods.
* Java OOP Product Inventory System - An Object-Oriented programming project implementing inheritance (`extends`), constructor chaining (`super`), and method overriding.

## 🛠 Skills & Topics Covered

As part of my pre-university revision plan, I am focusing on core Java fundamentals and Object-Oriented Programming:

- ✅ **Java Fundamentals:** Console input (`Scanner`), control flow, loops, and basic math operations.
- ✅ **Object-Oriented Programming (OOP):**
  - Classes & Objects
  - Constructors
  - **Inheritance (`extends`, `super`)**
  - Method Overriding
